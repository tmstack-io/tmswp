  - `AGENTS.md` / `CLAUDE.md` / `README.md`
  - `plugin.php`
  - `app/Hook/PluginSetupHook.php`
  - `app/{Post,Tax,User,Form,Model,Option,SettingsPage}` の空ディレクトリ
  - `tests/bootstrap.php` / `phpunit.xml.dist` / `phpstan.neon` / `.php-cs-fixer.dist.php` / `.gitignore`
  - `bin/setup.php`
- プラグインスターターの既定名前空間を `PluginApp\` にし、テーマスターターの `App\` と同一WordPress上で衝突しないようにした。
- スターターから設計と衝突していた `App\Models` サンプル、テーマ直下のサンプルフォームテンプレート、サンプル actions を撤去した。
- `tools/extract-rules-code.php` を追加し、`packages/core/rules/*.md` の PHP コードブロックを抽出できるようにした。抽出先重複は即失敗させる。
- `tools/verify-rules-code.php` を追加し、抽出した全PHP例の構文検査と `App\` クラス例のPHPStan解析を実行できるようにした。
- `.github/workflows/qa.yml` に `rules-verify` ジョブを追加し、rules コード例の抽出・構文検査・静的解析をCIで実行する入口を作った。
- `Kernel::boot()` がWordPressのプラグイン有効化サンドボックス(`WP_SANDBOX_SCRAPING`)では通常の属性初期化をスケジュールせず、activation/deactivation と Model migrator だけを登録するようにした。通常リクエストの遅延boot例外は維持する。
- ルート `CLAUDE.md` を追加し、`@AGENTS.md` 参照に一本化した。
