## 3. 実装内容の要約

- Kernelごとの登録とCLI(T1)
  - AcfBridgeを`ExtensionInterface`の実装にし、static状態と`boot()`・`config()`・`reset()`・`registerManagedKeys()`を廃止した。`KernelConfig`の`extensions`に`new AcfBridge(?BridgeConfig)`を渡し、テーマとプラグインで別々に登録できる。
  - `acf/json/save_paths`で、ACFが実際に読み込んだファイルが自分のacf-jsonにあるときだけ、そこへ書き戻す。対応するACFの下限を6.2にし、6.2より古いACFが有効なら設定の誤りとして例外にする。
  - 管理キーの申告を`Kernel::defer('init', 6)`で行い、生成物のAcfManifestが無いことを例外にする(WP-CLIのときだけ警告)。ACFの有無で処理を飛ばさない。Kernelは、boot中に`defer()`で発火済みのフックへ予約したものをキャッチアップの列に入れ、`defer()`を拡張の公開APIにした。
  - MetaSchemaRegistryの外部管理の申告に、ストレージと申告元を足した。同じストレージのエンティティの宣言を許し、重複の例外に定数名とACFのグループのkeyを含める。
  - CLIは`WP_CLI::`を直接呼び、`--app=`で対象のKernelを選ぶ。E101は、ManagedKeyCollectorで集めた管理キーを、全Kernelのレジストリの複製に申告して判定する。BridgeConfigの入力を検証する。
- 実行時アクセス(T2)
  - AcfMetaStorageは、ACFの書き込みの関数・フィルタ・post_idの解決を通さず、値をWpMetaStorageで読み書きし、ACFのフィールドのキーには参照のメタ`_{キー}`にfield keyを書き、最後にACFの値のキャッシュを消す。扱えるフィールドの型を、ACFの`update_value`が値を変えない単純な型に限り、ほかの型の書き込みは設定の誤り(`AcfBridgeRuntimeException`)にする。image・fileの単一の添付IDは、ACFと同じ規則で投稿に結び付ける。
  - AcfFieldAccessの型強制のヘルパで、未設定(null・false・'')と形の不一致を区別し、形の不一致はdebugで例外、本番でロガーに記録して未設定の値を返す。listは要素ごとに検査する。`has()`はメタの行の有無で判定する。date_time_pickerの夏時間の重複時刻は、早い方の瞬間だけを保存・返す。
  - 実物の無料版ACFで`MetaStorageContractTestCase`を通すAcfMetaStorageContractTestを足した。
- 生成コードの型と正規化(T3)
  - 生成アクセサ(getter・setter・`*AsDateTime`・`has*`・`delete*`)はfield key(`KEY_`定数)でACFを呼び、keyのフィールドがACFに登録されていなければ例外にする。名前で呼ぶのは、traitの公開のエスケープハッチ(`value()`・`rawValue()`・`update()`・`delete()`・`has()`)だけにした。
  - group・repeater・flexible_contentを全階層で正規化・検査する。生成される`of()`とAcfMetaStorageの全メソッドは、IDが1未満なら`InvalidArgumentException`にする。
  - traitの全メソッドを生成時にReflectionで集めて予約名にし、大文字小文字を区別せずに照合する。名前の衝突・`class`・PHPが整数のキーにするサブフィールド名はE002にする。ClassImportsで、生成クラスの名前と衝突するクラスを完全修飾名で参照する。
  - 手書きのtests/GeneratedAppを削除し、全31型の全設定のfixtureから生成したexpected-appを、PHPStan(level max)とphp-cs-fixerの対象に入れた。
- acf-jsonの読み込み(T4a)
  - 同じkeyのJSONを、jsonDirsの並び(テーマの既定では子テーマが先)で先勝ちにし、負けた側をW010で報告する。AcfBridgeはjsonDirsを`acf/settings/load_json`の末尾に逆順で置き、実行時のACFも生成と同じファイルを使う。
  - グループの判定を公式ACFの`get_files()`に揃え、配列形式のJSONと構文エラーをE102、非配列等をW001にした。各JSONを1回だけ読む。flexible_contentのレイアウトをJSONの順のlistにし、同じ名前・整数の名前のレイアウトをE002にした。
- locationの解決(T4b)
  - LocationResolverは、1つのANDグループの条件をすべて満たす1つのターゲットに解決し、決められないときはANDグループごとにW002を出す。post_templateに対応した。
  - 単一のテンプレートを条件に持つグループは、テンプレート別のクラス`{Studly}TemplateFields`に出す。W007は、ACFが画面の決まった値と比べる値源ではPHPの`==`で、それ以外のparamでは同じ文字列の`==`と`!=`だけで、成り立たない条件を検査する。locationのblockは非対応とし、W006で§1.11の方式を案内する。
- cloneの展開(T4c)
  - CloneResolverを、ACF Proのcloneの展開(保存名・ラベル・cloneのcloneの名前)を再現する形に書き直した。displayの既定はseamlessにした。
  - 展開したフィールドの`KEY_`定数と管理キーは元のkeyにし、prefix_nameで保存名が変わるフィールドは、元のkeyの定義のnameを保存名に差し替えて読み書きする。cloneが保存するメタを管理キーに入れた。
- 生成器の残りの機能と`tms-acf`(T4d)
  - coreに`KernelConfig::load()`を足し、テーマ・プラグインのルートの`tmswp-kernel.php`がKernelConfigを返す形にした(D-48)。
  - WordPressを起動しない`vendor/bin/tms-acf`(sync・check。`--dry-run`・`--strict`・`--root=`)を足した。生成と照合をSyncRunnerに移し、WP-CLIの`wp tmswp acf`と同じ処理を使う。checkは統一diffの先頭40行と、マーカーの無いPHPファイルのI002を出す。
  - flexible_contentのレイアウトのshapeを`@phpstan-type`の別名にした。`composer acf:check:fixtures`をcomposer qaとCIのStatic Analysisに入れた。
- プレビュー時のACFの値(T5)
  - 無料版ACF 6.8.10で、クラシックの編集画面のプレビューではACFがフィールドの値をautosaveへ保存し、親の投稿の値を変えないことを実測した。PreviewAcfSupportは、ACFの`save_post`より後に走るため正常な経路では何もせず、ACFが保存しないと決めた場合にだけ値を書いていた。PreviewAcfSupportとBridgeConfigの`previewMeta`を削除し、ACF標準の保存を統合テスト(AcfPreviewIntegrationTest)で固定した。
- rulesとREADME(T7)
  - packages/core/rules/acf.mdを、§1.9の使い分け、flexible_contentのmatchのイディオム、acf-jsonと生成物の同時コミットと`check --strict`、禁止事項、`value()`を含むレシピに書き直した。packages/acf-bridge/rules/sync-check.mdとREADMEを新設した。
  - tools/extract-rules-code.phpの抽出元をpackages/*/rulesに広げた(14ファイル・68件、PHPStanの対象は39件)。
- テスト(T6)
  - 全型のfixtureから生成したアクセサを実物のACFで確かめるAcfFieldTypesIntegrationTestを足した。無料版にある型はCIで、Proの型は手元のACF Pro(D-49)で確かめる。テストが触るACFのstoreを開始時の状態に戻すRestoresAcfStoresを足した。
  - Pro専用のテスト(`@group acf-pro`)を、ACF Proのzipを隔離したwp-envに載せて走らせる`composer test:integration:acf-pro`(tools/acf-pro-integration.sh)を足した(5.4)。
  - E003のメッセージにclassMap、W009のメッセージにmethodNameMapの回避方法の案内を足した(台帳のA5-low)。途中で見つけた不具合も直した(5.5)。
