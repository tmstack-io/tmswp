# v0.10.0受け入れ記録 — Modelの拡張

本書は、ロードマップ(`../12-implementation-plan.md`)のv0.10.0(§3.3)について、全版に共通する受け入れ条件(§0.3)とこの版の受け入れ条件を確認した結果を記録する。今はv0.10.0-T0(版の準備)の分だけを書いている。T1以降の確認の結果と、受け入れ条件ごとの検証結果は、各タスクと受け入れ確認のタスクが書き足す。

- T0の確認日: 2026-10-30

## 1. 版の目的

導入先のプロジェクトBの要望のうち、FWで吸収すると判断した5件(生成カラムとそれへの索引、トランザクションの実行単位、行ロックの句、upsert、`ON UPDATE CURRENT_TIMESTAMP`の列)をModelに足す。どれも、テーブルを変える唯一の経路(`wp tmswp migrate`)とMigratorの差分の検出、またはwpdbの境界(`Connection`)に関わる。あわせて、これらの機能が要るDBの最低の版を決める。

## 3. 版の準備(T0)

### 3.1 版の箇所

1つのコミットで、次を0.10.0に上げた(`../RELEASING.md`の手順2)。v0.10.0はMINORの版のため、v0.9.1と違い、制約は`^X.Y`の形にし、branch-aliasも上げた(§3.1)。

- `Kernel::VERSION`を`0.10.0`にした。
- packages/*・starters/*・examples/sample-siteのcomposer.jsonの`tmswp/*`の制約(`require`と`require-dev`)を`^0.9.1`から`^0.10`にした。
- packages/*のcomposer.jsonのbranch-alias(`dev-main`)を`0.9.x-dev`から`0.10.x-dev`にした。starters/*はbranch-aliasを持たない。
- examples/sample-siteのpathリポジトリの`versions`(6つ)を`0.10.0`にした。
- packages/*のrules/とREADME.mdの設計文書へのリンク(`blob/v0.9.1/`と、packages/core/README.mdの`tree/v0.9.1/`)を`v0.10.0`にした。`tests/Unit/RepositoryScanTest.php`の`testRulesAndReadmesLinkDesignDocumentsToTheTagOfKernelVersion`が、リンクの版と`Kernel::VERSION`の一致を確かめる。
- 版の例(packages/*/README.mdの要件の行、packages/core/rules/deploy.mdの「版をそろえる」の例、examples/sample-site/README.md、docs/01・02・08・11)を0.10.0と`^0.10`にした。deploy.mdの例は、制約を満たしても止まる2つの版を`0.10.0`と`0.10.1`にした。
- CHANGELOG.mdの先頭(説明文の後、`## v0.9.1 — 導入の支え`の前)に`## Unreleased`の節を開き、版の引き上げを「変更」に書いた。

リリースの前の検査(`tools/release/CheckReleaseReadinessReleaseWorker.php`)が照合する箇所は、`Kernel::VERSION`、packages/*とstarters/*の`tmswp/*`の制約とbranch-alias、examples/sample-siteの`tmswp/*`の制約とpathリポジトリの`versions`である。その版の照合(`versionFailures()`)をリフレクションで`0.10.0`について呼び、満たさない項目が無い(空の配列)ことを確かめた。

手元はPHP 8.5.10、Composer 2.10.3、Node.js 24.18.0、npm 11.16.0。ルートのwp-env(`@wordpress/env` 12.0.0、PHP 8.3)で確かめた。

- `composer monorepo:validate`: `[OK] All packages "composer.json" files use same package versions.`
- `git grep -nE '0\.9\.[0-9]|\^0\.9([^.0-9]|$)' -- packages starters examples docs/0*.md docs/1[01]*.md README.md AGENTS.md`: 残りは、examples/sample-siteとstarters/themeのpackage-lock.jsonのNode.jsの版の制約(`^20.9.0`等)とoptionatorの版(`^0.9.3`・`0.9.4`。どちらもTMSWPの版ではない)と、次の過去の版の事実の記述と、範囲外の古い記述の1件だけである。
  - 過去の版の事実の記述として残す:
    - docs/00 §4のDR-12とdocs/10の1066行・2037行: 合算カバレッジの85%の基準をv0.9.0で定めたという記述。

2026-10-30に、GitHubのAPI(`gh api`)、npmのレジストリ(`npm view`と、`npm audit`が使う勧告のAPI`https://registry.npmjs.org/-/npm/v1/security/advisories/bulk`)、手元の`npm audit`で確かめた。3つとも、回避を外せる更新は出ていなかった。docs/12 §3.3にタスクは足していない。
