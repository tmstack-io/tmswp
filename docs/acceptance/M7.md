# M7 Extensions acceptance

## 実装内容

- `tmswp/ja-toolkit` に `JaToolkit::enable()` と、管理メニュー/管理バー/ダッシュボード/head/ウィジェット整理、日本語スラッグ、全角スペース検索正規化、texturize無効化、エディタ調整の各オプトインモジュールを追加した。
- `tmswp/thumbnail` に `Thumbnail::register()` / `tms_thumb()` / 署名URL / uploads封じ込め `SourceResolver` / RESTコントローラ / キャッシュ / 本文画像フォールバック / WP-CLIキャッシュコマンドを追加した。
- `tmswp/csv-import` に `CsvImport::register()`、`Importer`、`CsvReaderFactory`、`CsvRow`、`ImportOptions`/`ImportResult`、`#[AsImporter]`、`ImporterMap`、`wp tmswp csv` コマンドを追加した。
- `tmswp/settings-page` に `SettingsPages::register()`、`#[AsSettingsPage]`、`SettingsPageInitializer`、`PageRegistrar`、`SettingsPageDefinition`、`OptionFormBridge` を追加した。
- `Form::applyDefaults()` を追加し、settings-page が OptionRepository の値をGET表示時のフォーム初期値へ流し込めるようにした。
- 4拡張パッケージと既存monorepoパッケージ/スターターの `tmswp/core` 依存制約を `^1.0` に統一した。

## 設計判断

- 拡張パッケージはすべて明示ブートのみで動作し、`register()` / `enable()` の二重呼び出しは `LogicException` にした。
- csv-import と settings-page の属性収集は独自探索を持たず、core Discovery の `ComponentAttributeInterface` 収集に乗せた。
- csv-import の ImporterMap は各Kernelのコンテナ管理とし、CLIコマンドが `Kernel::all()` からマージする。
- thumbnail のURL生成失敗は仕様どおり例外を外へ出さず、`Log::warning()` と空文字に固定した。RESTエンドポイント側は署名・サイズ・src解決エラーを `WP_Error` で明示拒否する。
- `ContentImageFallback` は既存coreの `PostType::thumbnail()` 契約に合わせ、URL文字列ではなく `TMSWP\Core\Post\Thumbnail` DTOを返す実装にした。
- settings-page の protected ライフサイクルメソッドは、`PageRegistrar` から呼ぶための `framework*` finalメソッドで橋渡しした。
