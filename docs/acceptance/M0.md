# M0 受け入れ記録

実施日: 2026-06-13

## 対象

M0: monorepo 骨格 + QA 基盤

## 検証結果

| 項目 | 結果 | 証跡 |
|---|---:|---|
| `composer validate --strict` | ✔ | ルート `composer.json is valid` |
| 各 package/starter `composer validate --strict` | ✔ | `packages/*` 6 件、`starters/*` 2 件が valid |
| `composer install --no-interaction` | ✔ | `vendor/` と `vendor-bin/wp-tests/vendor/` を生成 |
| `composer lint` | ✔ | php-cs-fixer: `Found 0 of 24 files that can be fixed` |
| `composer analyse` | ✔ | PHPStan: `[OK] No errors` |
| `composer test:unit` | ✔ | PHPUnit 11: `OK (6 tests, 6 assertions)` |
| `composer wp:start` | ✔ | 既存 8888/8889 利用中のため `.wp-env.override.json` で 8890/8891 を使用 |
| `composer test:integration` | ✔ | PHPUnit 9.6: `OK (1 test, 2 assertions)` |
| `composer qa` | ✔ | lint → analyse → unit → integration が exit code 0 |
| `composer monorepo:validate` | ✔ | `[OK] All packages "composer.json" files use same package versions.` |
| PHPStan baseline 不在 | ✔ | `find . -maxdepth 1 -name 'phpstan-baseline*' -print` が空 |
| `composer test:coverage` | ✘ | テストは通過するが、ローカル PHP に pcov/xdebug/phpdbg coverage driver が無く PHPUnit warning で exit code 1 |

## 追加確認

- `git init -b main` を実行し、ブランチは `main`。
- `vendor-bin/wp-tests` は PHPUnit 9.6 隔離のため `wp-phpunit/wp-phpunit` を `~6.4.0` に固定した。
- 統合テスト bootstrap では PHPUnit 11 との autoload 衝突を避けるため、`vendor-bin/wp-tests` 側 autoloader を優先登録している。

## 未達・要確認

- M0 のカバレッジゲートだけ未達。現在の PHP 8.3 CLI には coverage driver が無く、`phpdbg` でも PHPUnit 11 から coverage driver として認識されなかった。CI では `shivammathur/setup-php` の `coverage: pcov` で通す想定。ローカルで完了判定まで進めるには pcov または xdebug の導入が必要。
